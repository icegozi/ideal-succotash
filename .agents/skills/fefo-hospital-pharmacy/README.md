# FEFO Hospital Pharmacy

Skill chuyên cho module **FEFO (First Expired, First Out)** trong hệ thống quản lý kho thuốc bệnh viện.

## Dùng khi

- Thiết kế FEFO từ đầu
- Review luồng FEFO
- Phân bổ nhiều batch theo hạn dùng
- Xử lý cận hạn/hết hạn
- FEFO override
- Reservation
- Concurrency
- Audit
- Dashboard/cảnh báo FEFO
- Test nghiệp vụ FEFO

## Cách gọi gợi ý

```text
Use the fefo-hospital-pharmacy skill.

Review module FEFO hiện tại.
Chỉ phân tích và lập plan, chưa code.
Tập trung vào allocation, reservation, concurrency và audit.
```

Hoặc:

```text
Use the fefo-hospital-pharmacy skill.

Implement task này theo plan đã approve.
Áp dụng minimal patch và không thay đổi business logic ngoài phạm vi.
```
