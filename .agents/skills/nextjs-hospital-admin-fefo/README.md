# Next.js Hospital Admin + FEFO

Skill rút gọn dùng hằng ngày cho **Next.js Admin kho thuốc bệnh viện + FEFO**.

## Dùng khi

- Redesign UI admin
- Chuẩn hóa design system
- Tạo common component
- Làm dashboard kho thuốc
- Làm màn thuốc/lô/tồn kho
- Làm FEFO
- Sửa responsive
- Review UI/UX
- Lập plan trước khi code
- Implement theo minimal patch

## Prompt gọi nhanh

```text
Use the nextjs-hospital-admin-fefo skill.

Audit màn hình hiện tại và lập plan redesign.
Chưa code.
Ưu tiên usability, data readability và subtle 3D healthcare UI.
```

Hoặc:

```text
Use the nextjs-hospital-admin-fefo skill.

Implement plan đã approve.
Không sửa business logic ngoài phạm vi task.
Chạy checklist test sau khi hoàn thành.
```
